## Overview

The Parking EAFIT AI module generates automatic analytical reports about the occupancy status of the Central Parking lot. Using real-time data pulled from the database, it builds a contextualized prompt that is sent to **Google Gemini 2.5 Flash**, which returns a professional HTML-formatted analysis ready to be rendered in the browser and exported as a PDF.

## Setup & Installation

### 1. Install dependencies

```bash
pip install django google-generativeai
```

```python
# config/settings.py

## Gemini API Implementation

### SDK used

```python
import google.generativeai as genai
```

### Client configuration

```python
genai.configure(api_key=settings.GEMINI_API_KEY)
```

### Model initialization

```python
model = genai.GenerativeModel(
    'gemini-2.5-flash',
    system_instruction="Eres el sistema de reportes del Parking EAFIT."
)
```

The `system_instruction` parameter acts as the model's **system prompt**, defining its role and context before receiving any user message. Here it anchors the model to the domain of an institutional parking management system.

### Content generation

```python
response = model.generate_content(prompt)
reporte_html = response.text
```

`response.text` returns the plain text of the first candidate generated by the model.

### Response cleanup

Gemini occasionally wraps its response in Markdown code fences (` ```html ` / ` ``` `), even when instructed not to. The code applies a defensive cleanup:

```python
if reporte_html.startswith("```html"):
    reporte_html = reporte_html.replace("```html", "", 1).strip()
if reporte_html.endswith("```"):
    reporte_html = reporte_html.rsplit("```", 1)[0].strip()
```

## Report Generator Flow

### Step 1 — Real-time data extraction

```python
p_central = Parqueadero.objects.filter(nombre__icontains='central').first()
todas_celdas = Celda.objects.filter(parqueadero=p_central)

total_celdas = todas_celdas.count()
ocupadas = todas_celdas.filter(esta_ocupada=True).count()
libres = total_celdas - ocupadas
```

### Step 2 — Zone-by-zone breakdown (A–H)

```python
zonas = ['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H']
detalle_zonas = []

for zona in zonas:
    celdas_zona = todas_celdas.filter(numero__istartswith=zona)
    ocupadas_z = celdas_zona.filter(esta_ocupada=True).count()
    totales_z = celdas_zona.count()
    detalle_zonas.append(f"Zona {zona}: {ocupadas_z}/{totales_z} ocupadas.")

resumen_texto = "\n".join(detalle_zonas)
```

The parking lot is divided into 8 alphabetically labeled zones. Each parking cell has a `numero` field that starts with its zone letter (e.g. `A-01`, `B-12`). The `istartswith` filter is case-insensitive for robustness.

### Step 3 — Prompt construction

```python
prompt = f"""
Actúa como un experto analista de infraestructuras y parqueaderos universitarios.
A continuación se presentan los datos en tiempo real del Parqueadero Central:
- Ocupación global: {ocupadas} de {total_celdas} celdas están ocupadas.
- Celdas disponibles: {libres}.

Desglose por zonas:
{resumen_texto}

Por favor, elabora un breve reporte profesional (max 300 palabras).
Asegúrate de incluir recomendaciones sobre cómo distribuir mejor los vehículos.
Formatea el texto en HTML puro (puedes usar <h3>, <p>, <ul>, <li>, <strong>)
sin etiquetas Markdown de código cerradas, simplemente los tags HTML sueltos.
"""
```

The prompt follows prompt engineering best practices:

- **Explicit role**: "Act as an expert infrastructure and university parking analyst..."
- **Structured data**: global occupancy metrics + granular per-zone breakdown
- **Length constraint**: maximum 300 words for concise, scannable reports
- **Specified output format**: pure HTML with explicitly allowed tags
- **Concrete task**: analysis + vehicle redistribution recommendations

### Step 4 — Safe rendering

```python
from django.utils.safestring import mark_safe

return render(request, "reporte_ia.html", {"reporte": mark_safe(reporte_html)})
```

`mark_safe` tells Django that the HTML is already trusted and should not be escaped when rendered in the template. This is appropriate here because the content comes from a controlled API (Gemini), not from direct user input.

## Report Template

The `reporte_ia.html` template receives the `{{ reporte }}` variable and inserts it directly into the DOM inside the `.report-content` container:

```html
<div class="report-content">
    {% if error %}
        <div class="alert alert-danger">{{ error }}</div>
    {% else %}
        {{ reporte }}
    {% endif %}
</div>
```

Since the report is HTML generated by Gemini (using `<h3>`, `<p>`, `<ul>`, `<li>`, `<strong>`), scoped styles are applied in the template to render it correctly:

```css
.report-content h3 {
    color: #1e293b;
    font-weight: 700;
    margin-top: 1.5rem;
}
.report-content p,
.report-content li {
    color: #475569;
    line-height: 1.6;
}
```

The report header also displays a live timestamp generated client-side:

```html
<script>document.write(new Date().toLocaleString());</script>
```

## PDF Export

Export is handled via the browser's native print API — no external libraries required:

```javascript
function descargarPDF() {
    window.print();
}
```

To make the PDF look clean, the template includes `@media print` rules that hide navigation elements and strip shadows and borders from the report container:

```css
@media print {
    .top-header, .nav-bar, .export-section, .alert, .btn-close {
        display: none !important;
    }
    .report-wrapper {
        box-shadow: none !important;
        border: none !important;
        margin: 0 !important;
        padding: 0 !important;
    }
    .container {
        max-width: 100% !important;
        width: 100% !important;
    }
}
```

This guarantees the exported PDF contains **100% selectable text** (not a rasterized image), since the browser generates the PDF directly from the live DOM.

## Relevant Models

```python
# monitoreo/models.py

class Parqueadero(models.Model):
    nombre = models.CharField(max_length=100)
    espacios_ocupados = models.IntegerField(default=0)

    @property
    def total_celdas_reales(self):
        return self.celda_set.count()

    @property
    def espacios_ocupados_reales(self):
        return self.celda_set.filter(esta_ocupada=True).count()

    @property
    def espacios_libres_reales(self):
        return self.total_celdas_reales - self.espacios_ocupados_reales


class Celda(models.Model):
    parqueadero = models.ForeignKey(Parqueadero, on_delete=models.CASCADE)
    numero = models.CharField(max_length=10)   # e.g. "A-01", "B-05"
    esta_ocupada = models.BooleanField(default=False)
    placa = models.CharField(max_length=10, null=True, blank=True)
```
